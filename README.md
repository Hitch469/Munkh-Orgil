# 🌸 AETHERSTREAM

AETHERSTREAM is a modern anime-themed website built using **HTML5, CSS3, and JavaScript**. The project focuses on creating a clean, responsive, and visually engaging user interface inspired by anime streaming platforms.

Designed as a front-end web development project, AETHERSTREAM demonstrates responsive web design, interactive user interfaces, smooth animations, and organized page navigation while providing an enjoyable browsing experience for anime fans.

---

## 🚀 Features

- 🎌 Modern anime-inspired design
- 📱 Fully responsive layout
- 🎨 Clean and intuitive user interface
- ⚡ Smooth animations and transitions
- 📂 Multiple anime genre pages
- 🔍 Easy navigation
- 🌙 Dark-themed interface
- 💻 Built with HTML, CSS, and JavaScript
- 📖 Organized and maintainable project structure

---

## 🛠️ Technologies Used

- HTML5

- JavaScript (ES6)
- CSS Flexbox
- CSS Grid
- Responsive Web Design
